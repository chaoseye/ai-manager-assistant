# Отчёты eval-прогонов

Сюда `python -m evals.run_eval` пишет отчёты `eval-<дата>-<режим>.md`.

Прогона на реальной модели пока не было: для него нужен ключ Claude API (`LLM_MODE=live` и `ANTHROPIC_API_KEY` в `.env`). Отчёты mock-режима показывают только то, что скрипт работает: для большинства кейсов ответов модели там нет.
