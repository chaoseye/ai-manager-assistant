# Записанные ответы для mock-режима

Файлы здесь использует `MockLLMClient` (`LLM_MODE=mock`): если текст нового обращения совпадает с полем `match` (без учёта регистра и пунктуации), возвращается `suggestion` из файла. Для остальных обращений mock ищет похожий вопрос в `faq.yaml`, а если не находит — отвечает «уточню» с `needs_human=true`.

Ответы `01`–`07` к демо-сценариям из `examples/scenarios/` **составлены вручную** как эталон формата и поведения, а не получены от модели. После прогона на реальной модели их можно заменить настоящими ответами:

```bash
python -m evals.run_eval --only price-install,out-of-kb --record
```

Формат файла:

```json
{"id": "…", "match": "текст обращения", "suggestion": { …Suggestion… }}
```
