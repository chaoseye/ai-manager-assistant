Как это работает
  1. Сообщение уходит в сервис телом вебхука в формате amoCRM — через тот же разбор, что и у настоящего аккаунта.
  2. Сервис ждёт {{ debounce_seconds|round|int }} с тишины: клиент может дописать ещё.
  3. Фоновый обработчик берёт данные сделки из (поддельного) API amoCRM и вызывает ядро.
  4. Результат появляется в ленте сделки служебным примечанием «AI-помощник».

Ответьте за менеджера до конца паузы — примечание будет без черновика, только с допродажей.
